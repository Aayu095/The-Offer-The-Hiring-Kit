# Fonts

All files are SIL Open Font License builds, kept locally so the PDF
and image renderers never fetch anything.

- **Inter** (400/500/600/700) — full-coverage static TTFs instanced
  from the google/fonts variable font. Full coverage matters: the
  Fontsource latin subsets lack the rupee sign (U+20B9), and the
  renderers do no glyph fallback.
- **Fraunces** (500/600/700 + italics, opsz 72, WONK on) — instanced
  from the google/fonts variable font; cmap-verified for ₹.
- **Archivo** (400–900) and **Archivo Expanded** (wdth 125; 700/900)
  — instanced from the google/fonts variable font; ₹ verified.
- **IBM Plex Mono** (400/600) — static builds from google/fonts; ₹
  verified (unlike JetBrains Mono, which has no rupee glyph at all).
- **Bricolage Grotesque** (600/700/800, opsz 96) and **Manrope**
  (400/500/700/800) — instanced from the google/fonts variable
  fonts; ₹ verified.
